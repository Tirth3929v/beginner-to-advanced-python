# Day 64: My Top 10 Movies Website

Welcome to **Day 64** of the **#100DaysOfCode** Python Bootcamp!

## 📌 Project Overview
**My Top 10 Movies Website** is part of **Phase 3: Web & Flask**. This project focuses on building real-world software skills, mastering modern Python tools, and implementing clean software architecture.

---

## 🧠 Key Concepts Covered
- **Core Topics:** SQLAlchemy ORM, TMDB Movie API, Ranking Algorithm, Movie Card UI
- Clean code architecture and error handling
- Modular Python scripting and practical execution

---

## 🛠️ Requirements & Setup
Make sure you have Python 3.10+ installed.

If this project utilizes third-party packages, install them via `pip`:
```bash
pip install -r requirements.txt   # If applicable
```

---

## ⚡ How to Run
Execute the project from your terminal:
```bash
python main.py
```

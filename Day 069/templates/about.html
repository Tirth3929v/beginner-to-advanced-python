Day 69 Capstone Architecture

This project culminates the multi-day Web Development & Architecture module in the #100DaysOfCode curriculum. It introduces modern bidirectional relational data modeling, secure role-based access control (RBAC), and multi-user interaction.

Key Technical Highlights:

  • SQLAlchemy 2.0 Bidirectional Relationships: User acts as a parent to both BlogPost (articles authored) and Comment (feedback posted).
  • Granular RBAC Decorator: Custom @admin_only decorator enforces admin-exclusive operations (creating, editing, and deleting posts) while allowing registered users to participate in discussions.
  • Argon2id / PBKDF2 Password Hashing: Secure salt-based password generation and authentication via Werkzeug security primitives.
  • CSRF-Protected Forms & Jinja2 Templating: Full validation with WTForms, preventing cross-site request forgery and injection vulnerabilities.

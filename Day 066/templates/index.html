FLASK RESTful SERVICE

☕ Cafe & Wifi RESTful API

A production-grade JSON API supporting GET, POST, PATCH & DELETE operations with API Key auth.

GET /random Returns 200 OK

Fetches a randomized cafe from the database serialized as JSON.

🚀 Try in Browser
GET /all Returns 200 OK

Retrieves the complete catalogue of all registered laptop-friendly cafes.

🚀 Try in Browser
GET /search?loc={location} Returns 200 OK or 404

Filters cafes matching query parameter loc (e.g. London, San Francisco).

🚀 Try: /search?loc=London
POST /add Returns 201 Created

Registers a new cafe record. Accepts application/x-www-form-urlencoded or application/json.

curl -X POST http://127.0.0.1:5000/add -d "name=NewTechCafe&location=London&coffee_price=£3.20"
PATCH /update-price/{cafe_id}?new_price={price} Returns 200 OK or 404

Modifies only the coffee_price attribute of an existing cafe record without modifying other fields.

curl -X PATCH "http://127.0.0.1:5000/update-price/1?new_price=£3.80"
DELETE /report-closed/{cafe_id}?api-key={key} Returns 200 OK or 403 Forbidden

Permanently deletes a cafe from the database. Requires header api-key or query param api-key=TopSecretAPIKey.

curl -X DELETE "http://127.0.0.1:5000/report-closed/1?api-key=TopSecretAPIKey"

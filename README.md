# Beginner to Advanced Python: 100 Days, 100 Projects 🐍

Welcome to my 100 Days of Code challenge repository! 

Hi, I'm Tirth. While my regular Bachelor of Computer Applications (BCA) degree provided a strong, general foundation in computer science, this repository documents my dedicated deep dive into Python. 

As a developer with full-stack experience in the MERN stack and Angular 17, I am taking on this challenge to master backend logic, data handling, and automation. Ultimately, this journey is a stepping stone in my path as an aspiring AI Engineer, helping me solidify the prerequisite skills needed for advanced machine learning and predictive modeling.

## 🎯 Project Goals
* Consistently write and push code for 100 days.
* Transition from basic Python syntax to complex, object-oriented programming.
* Build a diverse portfolio covering web scraping, APIs, GUI apps, and data science.
* Integrate Python backend frameworks (like Flask) with my existing frontend knowledge.

## 🛠️ Technologies & Libraries Explored
Throughout this journey, I am working with a variety of industry-standard tools, including:
* **Core:** Python 3, Object-Oriented Programming (OOP)
* **Data Science & Analysis:** Pandas, NumPy, Matplotlib, Plotly, Seaborn
* **Web Development:** Flask, RESTful APIs, HTML/CSS/Bootstrap, SQLAlchemy
* **Automation & Scraping:** Selenium, BeautifulSoup, Requests, smtplib
* **GUI Creation:** Tkinter, Turtle

## 📂 Repository Structure
Each folder in this repository represents a single day of the challenge and contains a unique project. 

* `Day-01-to-14/`: Beginner Concepts (Data types, Control flow, Loops, Functions)
* `Day-15-to-53/`: Intermediate Concepts (OOP, File paths, CSVs, API integration, Web Scraping)
* `Day-54-to-71/`: Web Development (Flask, Templating, Databases, Authentication)
* `Day-72-to-81/`: Data Science & Analysis (Data exploration, Visualizations, Linear Regression)
* `Day-82-to-100/`: Professional Portfolio Projects

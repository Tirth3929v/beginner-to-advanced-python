## 🌟 Overview & Mission

Welcome to my **#100DaysOfCode** Python repository! 🚀

I'm **Tirth**, a full-stack web developer with experience in the **MERN stack** and **Angular 17**, holding a degree in Computer Applications (BCA). 

This repository serves as a live, practical record of my journey to master Python in depth. By building **100 projects in 100 days**, I am laying a bulletproof foundation in **backend mechanics, data structures, automation, data analysis, and AI/Machine Learning**.

### 🎯 Key Goals
- ⚡ **Daily Consistency:** Code and push clean, documented Python code every day for 100 days.
- 🏗️ **Solid Foundations to Advanced OOP:** Transition seamlessly from basic syntax to object-oriented architecture.
- 🌐 **Full-Stack Synergy:** Combine Python backend services (Flask, REST APIs) with modern frontend workflows.
- 🤖 **AI Engineering Readiness:** Build expertise in NumPy, Pandas, Matplotlib, and data pipelines for ML models.

## ⚡ Quick Start / How to Run

Want to test out any of the projects locally? Follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Tirth3929v/beginner-to-advanced-python.git
   cd beginner-to-advanced-python
   ```

2. **Navigate to any project directory:**
   ```bash
   cd "Day 5"
   ```

3. **Run the script:**
   ```bash
   python day_5_project.py
   ```

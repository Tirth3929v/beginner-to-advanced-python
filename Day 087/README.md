# Day 87: Cafe & Wifi Website

Welcome to **Day 87** of the **#100DaysOfCode** Python Bootcamp!

## 📌 Project Overview
**Cafe & Wifi Website** is part of **Phase 5: Portfolio**. This project focuses on building real-world software skills, mastering modern Python tools, and implementing clean software architecture.

---

## 🧠 Key Concepts Covered
- **Core Topics:** Flask Full-Stack, Bootstrap 5, SQLite/SQLAlchemy Database, Search Filtering

- Modular Python scripting and practical execution

pip install -r requirements.txt   # If applicable

# Day 95: Custom 2D Racing Game

Welcome to **Day 95** of the **#100DaysOfCode** Python Bootcamp!

## 📌 Project Overview
**Custom 2D Racing Game** is part of **Phase 5: Portfolio**. This project focuses on building real-world software skills, mastering modern Python tools, and implementing clean software architecture.

---

## 🧠 Key Concepts Covered
- **Core Topics:** Turtle/Pygame 2D Engine, Obstacle Avoidance Vectors, Acceleration & Scores
- Clean code architecture and error handling
- Modular Python scripting and practical execution

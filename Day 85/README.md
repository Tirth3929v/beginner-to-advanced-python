# Day 85: Typing Speed Test Desktop App

Welcome to **Day 85** of the **#100DaysOfCode** Python Bootcamp!

## 📌 Project Overview
**Typing Speed Test Desktop App** is part of **Phase 5: Portfolio**. This project focuses on building real-world software skills, mastering modern Python tools, and implementing clean software architecture.

## 🧠 Key Concepts Covered
- **Core Topics:** Tkinter Canvas, Timer Callbacks, Live WPM & Character Accuracy Calculation

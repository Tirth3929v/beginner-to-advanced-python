1. CSS Selectors in Action

CSS allows us to target elements by Element Type (e.g. p), by Class Name (e.g. .container), and by Unique ID (e.g. #selectors).

2. The Essential CSS Box Model

Every HTML element on the page is structured as a box consisting of 4 distinct layers:

  1. Content: The actual text or media inside the element.
  2. Padding: Clear space between the content and the border.
  3. Border: The outline surrounding the padding.
  4. Margin: Clear space outside the border, separating it from neighboring elements.

# Day 66: Building Your Own RESTful API

Welcome to **Day 66** of the **#100DaysOfCode** Python Bootcamp!

## 📌 Project Overview
**Building Your Own RESTful API** is part of **Phase 3: Web & Flask**. This project focuses on building real-world software skills, mastering modern Python tools, and implementing clean software architecture.

---

## 🧠 Key Concepts Covered
- **Core Topics:** REST Architecture, GET/POST/PATCH/DELETE Endpoints, Postman, JSON Responses
- Clean code architecture and error handling
- Modular Python scripting and practical execution

---

## 🛠️ Requirements & Setup
Make sure you have Python 3.10+ installed.

If this project utilizes third-party packages, install them via `pip`:
```bash
pip install -r requirements.txt   # If applicable
```

---

## ⚡ How to Run
Execute the project from your terminal:
```bash
python main.py
```
